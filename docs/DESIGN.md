# PiP-first userscript v0.4.7

## 境界

Google検索content script相当の処理 → Tampermonkey GMストレージ → 明示起動したGeminiウィンドウ → Gemini DOM操作・回答監視 → GMストレージ → Google回答カード。
PiPはGeminiウィンドウが所有します。GeminiのDOMを移さず、テキストの補助表示に使います。
所有ウィンドウは閉じません。PiPが可視の間だけ自動送信・回答観測を行います。
拡張機能の権限やService Workerは使用しません。元の拡張版リポジトリは別管理です。

## 表示

検索側は起動ボタンだけで始め、生成時に状態・回答を追加します。完了後の重複見出しは省きます。
回答は構造化されたtextContentで描画し、リンクだけ許可URLを使います。
回答は途中表示・完成表示ともに最大210pxまたは画面高の27.5%の小さい方へ収めます。実際に溢れる場合だけ「もっと見る」を表示し、全文・出典を展開できます。「折りたたむ」で戻せます。同じジョブの更新では展開状態を保ち、別ジョブではリセットします。折りたたみ中の出典は非表示・inertにし、見えないリンクへフォーカスが移らないようにします。
実会話へのリンクは高さ制限の外で、本文直後の全幅ボタン「Geminiを開いて会話を続ける」にします。短い回答ではこの会話ボタンだけを表示し、全文展開時は会話ボタンの次に「折りたたむ」を置きます。未展開の長い回答では会話ボタンを非表示にし、「もっと見る」だけを表示します。再折りたたみ時や途中回答が高さ上限を超えたときも会話ボタンを非表示へ戻します。
正常なPiP準備完了状態、または正常な回答表示中の起動ボタンは右下の小さな補助操作にします。PiP準備完了であれば、回答のない待機・送信中も同じ右下配置です。準備完了状態は同意済み、現在のプロトコル、新鮮なworker接続、pipReadyをService Workerなしの既存Google処理で確認してカードへ渡します。PiP未準備の初期状態や確認必要状態では従来の目立つボタンを保ちます。
Gemini側は全面の起動案内です。独自dialogではなくshadow DOM内のregionにし、Geminiの操作確認検出と干渉させません。
Gemini本体を表示する操作は実行中の自動操作を中断します。

frontend-designで採用した見た目は、白・青灰とコバルトの小さなユーティリティUIです。
色は `#FFFFFF` / `#F2F5FC` / `#243149` / `#D8E0EF` / `#415FC8`、準備完了の補助色は `#287C75`。
フォントは日本語のシステムフォントを使用し、外部フォントを読み込みません。

```text
検索: [Geminiウィンドウを開く] → [本文 / 全幅の会話ボタン / 必要なら展開・折りたたみ / 右下の補助起動ボタン]
Gemini: [説明と同意 / PiP開始] → [PiP表示中 / 本体は最小化可・閉じない]
```

検索UIに起動説明や設定を詰め込まず、説明はGemini側へ寄せます。
カードは通常結果の列に配置し、完了状態が変わらない限りDOMを再生成しません。

## 送信と安全停止

- 明示的なPiP開始クリックでv0.4の同意を取得します。旧版と異なるストレージ名前空間を使います。
- workerは1つ、実行は1件。各検索タブには最新1件の未送信スロットがあります。
- sourceは受理前にジョブIDを破棄しません。workerがDOM操作前に受理記録を保存し、重複IDを拒否します。
- 受理記録は5分だけ有効です。期限切れ・閉鎖復旧でも同じ検索を別IDで自動再送しません。
- 最後に受理されたジョブの参照をタブ状態に保持します。完了後のページ再読み込みでも、検索語・source・job ID・期限が一致する受理記録から、完了・エラーなど終端状態の表示だけを復元します。放棄済みの生成中状態は復元しません。
- URLの検索語以外の更新では表示を消しません。旧版に参照がない場合、最新回答を推測で紐付けず、復元不可と案内します。
- 新規チャットを確認し、nativeのuser-queryが送信検索語と一致したときだけ会話URLを固定します。質問本文は `.query-text-line` 段落を優先し、読み上げラベルを含む外側の領域を使いません。
- 失敗・復元不可の場合だけ明示再送ボタンを表示します。クリック時に同意・PiP・worker・共有request・idleを再確認し、旧記録を保持したまま新しいmanual jobを1件作ります。後続の検索は通常のautoです。
- 生成中の別チャット移動、ブラウザの戻る操作、Gemini本体の手動確認で取得を中断します。
- PiPを閉じた生成中ジョブは同じobserver・期限を保持します。再表示で取得を再開し、送信は繰り返しません。

Google側のAI表示変更は独立した小さなmoduleです。既知マーカーだけを隠し、検索全体や通常結果を含む領域は保護します。
確認済みの `#eKIzJc.SePcAf` が本文マーカーと所属するAI概要の展開操作を持ち、保護領域・外側の通常結果を含まない場合だけ、外枠ごと非表示にします。`data-lhcontainer`は深い非同期子要素に移る場合があるため、外枠と同じ要素にあることは要求しません。それ以外はマーカー単体に戻します。検索ナビ`#hdtb`も保護します。
AIモードの置換は新しいanchorを使い、元のanchorとdiv/spanラベル経路の配置クラスだけ再構築します。イベント・RPC属性は複製しません。文字は非アクティブ項目と同じ色、下線なしとし、左に装飾用Geminiアイコンを添えます。アイコンは同梱data SVGで、外部通信は行いません。
AIモードリンクはnative会話URLへ差し替え、回答カードと同じ対象にします。
